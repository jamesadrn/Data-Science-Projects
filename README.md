# Projects
1. [Cancer Prediction](./Cancer%20Prediction)
   - Objective: The projects predicts the cancer diagnosis in the value 0 or 1. 1 indicates cancer and 0 indicates no cancer. prediction based on patients’ medical history.
   - Models: Logistic Regression, Random Forest, and XGBoost
   - Results: The XGBoost Classifier achieved the best performance with 94.3% accuracy, outperforming Random Forest (92.3%) and Logistic Regression (86%)
